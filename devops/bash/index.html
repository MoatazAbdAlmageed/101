⚡ Bash Commands Cheatsheet

A quick reference for popular Bash commands — perfect for beginners

📁 Navigation
pwdPrint current working directory
lsList files in current directory
ls -laList all files with details
cd <dir>Change to a directory
cd ..Go up one directory
cd ~Go to home directory
cd -Go to previous directory
📄 File Operations
touch file.txtCreate an empty file
cp src destCopy file or directory
mv src destMove or rename file
rm fileDelete a file
rm -rf dirDelete directory recursively
mkdir dirCreate a new directory
mkdir -p a/b/cCreate nested directories
📝 Viewing & Text
cat filePrint file contents
less fileScroll through file
head -n 10 fileShow first 10 lines
tail -n 10 fileShow last 10 lines
grep "text" fileSearch text in file
wc -l fileCount lines in file
echo "hello"Print text to terminal
🔐 Permissions
chmod 755 fileSet file permissions
chmod +x fileMake file executable
chown user fileChange file owner
sudo commandRun as superuser
su - userSwitch to another user
whoamiShow current username
⚙️ Processes
ps auxList all running processes
topLive process monitor
htopInteractive process viewer
kill <pid>Kill process by ID
kill -9 <pid>Force kill a process
bg / fgSend/bring process to background/foreground
Ctrl + CInterrupt/stop current process
🌐 Networking
ping hostCheck connectivity to host
curl URLFetch content from URL
wget URLDownload file from URL
ssh user@hostConnect to remote server
scp src user@host:destCopy file to remote server
ifconfig / ip aShow network interfaces
netstat -tulnShow listening ports
📦 Archives
tar -czf out.tar.gz dirCompress directory to .tar.gz
tar -xzf file.tar.gzExtract .tar.gz archive
zip -r out.zip dirZip a directory
unzip file.zipUnzip an archive
gzip fileCompress file with gzip
gunzip file.gzDecompress gzip file
💡 Variables & Scripting
VAR="value"Assign a variable
echo $VARPrint a variable
export VARExport variable to environment
$0, $1, $2Script name and arguments
$?Exit code of last command
#!/bin/bashShebang — start of a script
bash script.shRun a bash script
