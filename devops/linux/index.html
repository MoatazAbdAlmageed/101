🔍 Regex
⚓ Anchors
^Match start of line
$Match end of line
\bWord boundary
\BNon-word boundary
\AStart of string (PCRE)
\ZEnd of string (PCRE)
🔢 Quantifiers
*0 or more times
+1 or more times
?0 or 1 time (optional)
{n}Exactly n times
{n,}At least n times
{n,m}Between n and m times
*? +? ??Lazy (non-greedy) versions
🔡 Character Classes
.Any character except newline
\dDigit [0-9]
\DNon-digit
\wWord char [a-zA-Z0-9_]
\WNon-word character
\sWhitespace (space, tab…)
\SNon-whitespace
[abc]One of: a, b, or c
[^abc]NOT a, b, or c
[a-z]Any lowercase letter
[A-Z0-9]Uppercase or digit
🔗 Groups & Alternation
(abc)Capture group
(?:abc)Non-capturing group
(?=abc)Positive lookahead
(?!abc)Negative lookahead
(?<=abc)Positive lookbehind
(?<!abc)Negative lookbehind
a|bAlternation — a OR b
\1 \2Backreference to group 1, 2
🔎 grep with Regex
grep 'pat' fileBasic search
grep -E 'pat' fileExtended regex (ERE)
grep -P 'pat' filePerl-compatible regex (PCRE)
grep -i 'pat' fileCase-insensitive
grep -v 'pat' fileInvert match (exclude)
grep -n 'pat' fileShow line numbers
grep -c 'pat' fileCount matching lines
grep -o 'pat' filePrint only matched part
grep -r 'pat' dir/Recursive search
grep -l 'pat' *.txtList matching filenames only
✏️ sed with Regex
sed 's/old/new/' fileReplace first match per line
sed 's/old/new/g' fileReplace all matches
sed 's/old/new/gi' fileReplace all, case-insensitive
sed -i 's/old/new/g' fEdit file in-place
sed '/pat/d' fileDelete lines matching pattern
sed -n '/pat/p' filePrint only matching lines
sed 's/\(grp\)/[\1]/'Use capture group in replace
sed 's/^/ /' fileIndent every line
sed '/^$/d' fileRemove blank lines
⚙️ awk with Regex
awk '/pat/' filePrint lines matching pattern
awk '!/pat/' filePrint non-matching lines
awk '$2 ~ /pat/'Match regex in field 2
awk '$2 !~ /pat/'Field 2 does NOT match
awk '{gsub(/old/,"new"); print}'Global substitute
awk '{sub(/old/,"new"); print}'First match substitute
awk 'NR==2,/end/'Range from line 2 to pattern
