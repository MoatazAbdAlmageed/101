# Vue.js Mastery Roadmap

## Phase 1: Foundations
- **Branch:** `phase-01-foundations`
- **Topics:**
  - Introduction to Vue.js (CDN vs. Vite)
  - The Vue Instance & Reactivity
  - Template Syntax & Directives (`v-bind`, `v-if`, `v-for`, `v-on`, `v-model`)
  - Computed Properties & Watchers
- **Objective:** Build a simple interactive counter and list.

## Phase 2: Component Architecture
- **Branch:** `phase-02-components`
- **Topics:**
  - Single File Components (SFCs)
  - Props & Custom Events
  - Lifecycle Hooks
  - Slots & Teleport
- **Objective:** Create modular UI components.

## Phase 3: State Management & Routing
- **Branch:** `phase-03-ecosystem`
- **Topics:**
  - Vue Router
  - Pinia (State Management)
  - Fetching Data (Axios/Fetch)
- **Objective:** Build a multi-page SPA.

## Phase 4: Composition API & Mastery
- **Branch:** `phase-04-mastery`
- **Topics:**
  - Composition API Patterns
  - Custom Composables
  - Performance Optimization
  - Testing with Vitest
- **Objective:** Refactor and optimize for scale.
