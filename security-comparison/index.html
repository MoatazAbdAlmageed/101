Data Transformation

Hashing vs. Encryption vs. Encoding

تحويل البيانات

التجزئة مقابل التشفير مقابل الترميز

🔒 Hashing

A one-way process that transforms data into a fixed-length signature. It is impossible to reverse.

One-Way Fixed Length Integrity

🔒 التجزئة (Hashing)

عملية أحادية الاتجاه تحول البيانات إلى توقيع بطول ثابت. من المستحيل استعادة البيانات الأصلية.

اتجاه واحد طول ثابت سلامة البيانات

🔑 Encryption

A two-way process used for secrecy. Requires a specific key to lock and unlock the data.

Two-Way Secret Key Privacy

🔑 التشفير (Encryption)

عملية ثنائية الاتجاه تستخدم للسرية. تتطلب مفتاحاً خاصاً لقفل وفتح تشفير البيانات.

اتجاهين مفتاح سري الخصوصية

📦 Encoding

Changing data format for compatibility. Not meant for security, as no key is required.

Compatibility No Key Public Scheme

📦 الترميز (Encoding)

تغيير تنسيق البيانات لضمان التوافقية. لا يقصد به الأمن، حيث لا يتطلب مفتاحاً سرياً.
