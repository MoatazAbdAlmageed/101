# DSA Capstone Projects

This directory contains four diverse projects that apply the concepts from our DSA Learning Roadmap to real-world scenarios.

## Projects Overview

### 1. [Algorithm Visualizer](1_visualizer/index.html)
A premium web-based interface to visualize sorting algorithms in real-time.
- **Key Features:** Supports Bubble, Selection, Insertion, Quick, and Merge sorts. Adjust speed and array size dynamically.
- **Tech Stack:** HTML5, CSS3 (Dark/Neon aesthetic), JavaScript.

### 2. [Mini Search Engine](2_search_engine/search_engine.py)
A text indexing and search system inspired by modern search engines.
- **Key Features:** Trie-based indexing, instant word search, and auto-complete functionality.
- **Tech Stack:** Python.

### 3. [File Compression Utility](3_compression/huffman.py)
A tool for reducing file size using optimal encoding.
- **Key Features:** Huffman Coding implementation, frequency analysis, and lossless decompression.
- **Tech Stack:** Python.

### 4. [Social Network Graph](4_social_network/social_graph.py)
An analysis tool for modeling and querying social relationships.
- **Key Features:** Dijkstra's shortest path, mutual friend detection, and "Friend of Friend" recommendations.
- **Tech Stack:** Python.

---

## How to Run

- **Visualizer:** Open `1_visualizer/index.html` in any modern web browser.
- **Python Tools:** Run the scripts using `python filename.py` from their respective directories.
