# Setup & Environment 🛠️

Before we start coding, we need to set up our tools.

## 1. Installing Python

Go to [python.org](https://www.python.org/downloads/) and download the latest version for Windows.

- **Important:** During installation, make sure to check the box that says **"Add Python to PATH"**.

## 2. Choosing an Editor (IDE)

While you can write Python in Notepad, it's better to use a tool that helps you.

- **VS Code (Recommended):** Lightweight and powerful.
- **PyCharm:** Professional IDE for Python.
- **Jupyter Notebook:** Great for learning and data science.

## 3. Your First Check

Open your terminal (PowerShell or CMD) and type:

```bash
python --version
```

If you see something like `Python 3.10.x`, you're good to go!

## 4. The Interactive Shell

Type `python` in your terminal. You are now in the Python REPL (Read-Eval-Print Loop).
Try typing:

```python
print("Hello World!")
```

Press Enter. You've just run your first Python code!
