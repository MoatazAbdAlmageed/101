1. Introduction to Prompt Engineering / مقدمة في هندسة الأوامر

Introduction & Explanation

Prompt engineering is the process of structuring natural language inputs to produce specified outputs from a generative artificial intelligence (GenAI) model. A prompt is a text query or instruction that describes the task the AI should perform. Good prompts equal good results, allowing the model to better comprehend nuance and intent behind the query.

Examples

Example 1: Basic QA

"What is the capital of France?"

Example 2: Text Summarization

"Summarize this legal document into 3 bullet points suitable for a 10-year-old."

Example 3: Content Generation

"Write a short, engaging email inviting a client to a software demo."

Mini Exercise

Task:

Write a prompt to get a recipe for a chocolate cake.

Show Answer

"Provide a step-by-step recipe for a moist chocolate cake, including a list of ingredients and baking time."

Summary

Prompt engineering bridges the gap between raw queries and meaningful AI outputs, saving time and ensuring accuracy.

المقدمة والشرح

هندسة الأوامر هي عملية هيكلة المدخلات باللغة الطبيعية لإنتاج مخرجات محددة من نموذج ذكاء اصطناعي توليدي. الأمر (Prompt) هو استعلام نصي أو تعليمة تصف المهمة التي يجب على الذكاء الاصطناعي أداؤها. الأوامر الجيدة تعني نتائج جيدة، مما يسمح للنموذج بفهم الفروق الدقيقة والقصد وراء الاستعلام بشكل أفضل.

الأمثلة

مثال 1: سؤال وجواب أساسي

"ما هي عاصمة فرنسا؟"

مثال 2: تلخيص النصوص

"لخّص هذه الوثيقة القانونية في 3 نقاط تناسب طفلاً في العاشرة من عمره."

مثال 3: إنشاء المحتوى

"اكتب بريداً إلكترونياً قصيراً وجذاباً لدعوة عميل لحضور عرض توضيحي للبرنامج."

تمرين مصغر

المهمة:

اكتب أمراً للحصول على وصفة لكعكة الشوكولاتة.

إظهار الإجابة

"قدم وصفة خطوة بخطوة لكعكة شوكولاتة هشة، متضمنة قائمة المكونات ووقت الخبز."

الملخص

تسد هندسة الأوامر الفجوة بين الاستعلامات الخام ومخرجات الذكاء الاصطناعي المفيدة، مما يوفر الوقت ويضمن الدقة.

2. Core Principles of Prompting / المبادئ الأساسية للتوجيه

Introduction & Explanation

Effective prompting rests on four core principles: Clarity, Context, Precision, and Role-play. Avoiding ambiguity (Clarity) and providing background information (Context) are essential. Additionally, assigning the AI a specific persona (Role-play) guides its responses effectively. Structuring prompts with message roles (like developer for system instructions and user for inputs) helps guide the logic perfectly.

Examples

Example 1: Precision

Instead of "Tell me about dogs," use: "Provide a detailed description of the characteristics and care required for domestic dogs."

Example 2: Context

"Translate the following English text to French: 'Hello, how are you?'"

Example 3: Role-Play

"As a data visualization expert, explain the concept of creating a 'Box Plot'."

Mini Exercise

Task:

Transform this vague prompt into a precise, role-based prompt: "Help me write a resume."

Show Answer

"As a career coach, provide a step-by-step guide to writing an effective resume for a data scientist, including key skills and project sections."

Summary

Always be explicit. Establish a clear context, ask for exact formats, and use role-play to tune the depth and tone of the AI.

المقدمة والشرح

يعتمد التوجيه الفعال على أربعة مبادئ أساسية: الوضوح، السياق، الدقة، ولعب الأدوار. تجنب الغموض (الوضوح) وتوفير المعلومات الأساسية (السياق) أمران ضروريان. بالإضافة إلى ذلك، فإن إعطاء الذكاء الاصطناعي شخصية معينة (لعب الأدوار) يوجه ردوده بفعالية. كما أن هيكلة الأوامر بأدوار الرسائل (مثل دور المطور للتعليمات ودور المستخدم للمدخلات) توجه المنطق بشكل مثالي.

الأمثلة

مثال 1: الدقة

بدلاً من "أخبرني عن الكلاب"، استخدم: "قدم وصفاً تفصيلياً للخصائص والرعاية المطلوبة للكلاب الأليفة."

مثال 2: السياق

"ترجم النص الإنجليزي التالي إلى الفرنسية: 'مرحباً، كيف حالك؟'"

مثال 3: لعب الأدوار

"بصفتك خبيراً في تصور البيانات، اشرح مفهوم إنشاء 'المخطط الصندوقي'."

تمرين مصغر

المهمة:

حوّل هذا الأمر الغامض إلى أمر دقيق يعتمد على الأدوار: "ساعدني في كتابة سيرة ذاتية."

إظهار الإجابة

"بصفتك مدرباً مهنياً، قدم دليلاً خطوة بخطوة لكتابة سيرة ذاتية فعالة لعالم بيانات، متضمنة المهارات الرئيسية وقسم المشاريع."

الملخص

كن دائمًا صريحًا. قم بإنشاء سياق واضح، واطلب تنسيقات دقيقة، واستخدم أسلوب لعب الأدوار لضبط عمق ونبرة الذكاء الاصطناعي.

3. Advanced Prompting Techniques / تقنيات التوجيه المتقدمة

Introduction & Explanation

To unlock an LLM's full potential, experts use advanced methods:

1. Few-Shot Prompting: Providing a handful of input/output examples inside the prompt to teach the model a pattern.
2. Chain-of-Thought (CoT): Forcing the model to solve a problem as a series of intermediate steps ("Let's think step-by-step"), improving reasoning accuracy.
3. Retrieval-Augmented Generation (RAG): Combining prompts with external document retrieval to eliminate hallucinations and base responses on actual data.

Examples

Example 1: Few-Shot 
Text: "I love this phone!" -> Positive
Text: "Screen broke in 2 days." -> Negative
Text: "Battery life is okay." -> Neutral
Text: "Customer service was terrible." ->
Example 2: Chain-of-Thought

"If John has 5 apples, eats 2, and buys 4 more, how many does he have? Let's think step-by-step."

Example 3: Least-to-Most

"To solve [complex problem], first break it down into subproblems, then solve them in sequence."

Mini Exercise

Task:

How would you write a zero-shot prompt vs. a one-shot prompt for translating English to French?

Show Answer

Zero-shot: "Translate 'House' to French."
One-shot: "English: Cat -> French: Chat. English: House -> French:"

Summary

Advanced techniques like CoT and Few-Shot allow models to reason deeply, reduce errors, and learn specific formatting directly from context.

المقدمة والشرح

لإطلاق الإمكانات الكاملة للنماذج اللغوية، يستخدم الخبراء طرقاً متقدمة:

1. التوجيه ببضعة أمثلة (Few-Shot): توفير مجموعة من أمثلة الإدخال/الإخراج داخل الأمر لتعليم النموذج نمطاً معيناً.
2. سلسلة الأفكار (CoT): إجبار النموذج على حل مشكلة كسلسلة من الخطوات الوسيطة ("دعونا نفكر خطوة بخطوة")، مما يحسن دقة الاستنتاج.
3. التوليد المعزز بالاسترجاع (RAG): دمج الأوامر مع استرجاع مستندات خارجية للتخلص من الهلوسة وبناء الردود على بيانات فعلية.

الأمثلة

مثال 1: بضعة أمثلة (Few-Shot) 
Text: "I love this phone!" -> Positive
Text: "Screen broke in 2 days." -> Negative
Text: "Customer service was terrible." ->
مثال 2: سلسلة الأفكار

"إذا كان لدى جون 5 تفاحات، أكل 2، واشترى 4 أخرى، فكم تفاحة لديه؟ دعونا نفكر خطوة بخطوة."

مثال 3: من الأقل إلى الأكثر (Least-to-Most)

"لحل [المشكلة المعقدة]، قم أولاً بتقسيمها إلى مشاكل فرعية، ثم قم بحلها بالتسلسل."

تمرين مصغر

المهمة:

كيف تكتب أمراً بدون أمثلة (Zero-shot) مقابل أمر بمثال واحد (One-shot) لترجمة الإنجليزية إلى الفرنسية؟

إظهار الإجابة

بدون أمثلة: "ترجم 'House' إلى الفرنسية."
بمثال واحد: "إنجليزي: Cat -> فرنسي: Chat. إنجليزي: House -> فرنسي:"

الملخص

تسمح التقنيات المتقدمة مثل (CoT) و (Few-Shot) للنماذج بالاستنتاج بعمق، وتقليل الأخطاء، وتعلم التنسيقات المحددة مباشرة من السياق.

4. Real-world Use Cases & Exercises / حالات الاستخدام العملية والتمارين

Introduction & Explanation

In professional environments, prompt engineering is heavily used for software generation, healthcare analytics, and customer service. Writing robust prompts requires adjusting the tone, dealing with prompt injection attacks, and explicitly restricting output length or format to optimize the workflow. Adding XML tags around inputs can also heavily improve structure for API outputs.

Examples

Example 1: Software Dev

"You are an expert React developer. Write a reusable Button component in Tailwind CSS. Restrict output to code only. Do not include markdown explanations."

Example 2: Healthcare

"Review the following patient data inside the <data> tags. Summarize the symptoms in a bulleted list."

Example 3: Debugging Tone

"Rewrite this technical explanation about quantum computing. Explain it to me like I am a 5-year-old using simple analogies."

Mini Exercise

Task:

Your AI is returning too much conversational text when generating JSON. How do you fix the prompt?

Show Answer

Add an explicit constraint: "Return ONLY valid JSON. Do not include introductory text, conversational filler, or markdown blocks."

Summary

Real-world prompting is an iterative engineering process. Constrain the outputs, format data correctly with tags, and continually debug tone and logic.

المقدمة والشرح

في بيئات العمل الاحترافية، تُستخدم هندسة الأوامر بكثافة لتوليد البرمجيات، تحليلات الرعاية الصحية، وخدمة العملاء. تتطلب كتابة الأوامر القوية تعديل النبرة، التعامل مع هجمات حقن الأوامر، وتقييد طول أو تنسيق المخرجات بوضوح لتحسين سير العمل. يمكن أن تؤدي إضافة علامات XML حول المدخلات إلى تحسين الهيكل بشكل كبير لمخرجات واجهة برمجة التطبيقات (API).

الأمثلة

مثال 1: تطوير البرمجيات

"أنت مطور React خبير. اكتب مكون زر (Button) قابل لإعادة الاستخدام باستخدام Tailwind CSS. اقتصر في المخرجات على الشفرة البرمجية فقط. لا تقم بتضمين شروحات نصية."

مثال 2: الرعاية الصحية

"راجع بيانات المريض التالية داخل علامات <data>. لخص الأعراض في قائمة نقطية."

مثال 3: تصحيح النبرة

"أعد كتابة هذا الشرح التقني حول الحوسبة الكمية. اشرحه لي وكأنني طفل في الخامسة من عمري باستخدام تشبيهات بسيطة."

تمرين مصغر

المهمة:

الذكاء الاصطناعي يُرجع نصاً حوارياً كثيراً عند إنشاء JSON. كيف تقوم بإصلاح الأمر؟

إظهار الإجابة

أضف قيداً صريحاً: "أعد ملف JSON صالحاً فقط. لا تقم بتضمين نص تمهيدي أو حشو حواري أو كتل ماركداون."

الملخص

التوجيه في العالم الحقيقي هو عملية هندسية تكرارية. يجب تقييد المخرجات، وتنسيق البيانات بشكل صحيح باستخدام العلامات، وتصحيح الأخطاء المنطقية والنبرة باستمرار.
