فهم الفلسفة وراء TypeScript وتجهيز بيئة التطوير الخاصة بك.

Page 1

What is TypeScript?

ما هي TypeScript؟

TypeScript is a programming language developed by Microsoft that builds on top of JavaScript by adding static typing. It acts as a "superset" of JavaScript, meaning that every valid JavaScript file is essentially a valid TypeScript file. However, unlike vanilla JavaScript, which dynamically determines variable types at runtime, TypeScript allows you to define types explicitly while coding.

TypeScript هي لغة برمجة طورتها مايكروسوفت تبني فوق JavaScript عن طريق إضافة أنواع ثابتة (Static Typing). تعمل كـ "مجموعة فائقة" (Superset) من JavaScript، مما يعني أن كل ملف JavaScript صالح هو في الأساس ملف TypeScript صالح. ومع ذلك، على عكس JavaScript الخام التي تحدد أنواع المتغيرات ديناميكيًا وقت التشغيل، تسمح لك TypeScript بتعريف الأنواع صراحةً أثناء البرمجة.

intro.ts
// JavaScript
let message = "Hello";
message = 123; // Valid in JS, but potential bug

// TypeScript
let secureMessage: string = "Hello";
// secureMessage = 123; // Error: Type 'number' is not assignable to type 'string'
Page 2

The Compilation Step

خطوة التجميع (Transpilation)

Because browsers and standard runtime environments do not execute TypeScript natively, the code requires a compilation step to translate it into standard JavaScript. This process is officially known as "transpilation". Using the TypeScript Compiler, you convert your .ts files into standard .js files.

نظرًا لأن المتصفحات وبيئات التشغيل القياسية لا تنفذ TypeScript بشكل أصلي، فإن الكود يتطلب خطوة تجميع لترجمته إلى JavaScript قياسي. تُعرف هذه العملية رسميًا باسم "transpilation". باستخدام مترجم TypeScript، تقوم بتحويل ملفات .ts الخاصة بك إلى ملفات .js قياسية.

terminal
# Compiling a specific file
tsc index.ts

# Compiling the entire project
tsc
Page 3

Setting Up Your Environment

إعداد بيئة العمل

To begin working with TypeScript, you must first have Node.js installed on your machine. Once installed, you utilize the Node Package Manager (NPM) to install the compiler globally by running the command npm i -g typescript.

لبدء العمل مع TypeScript، يجب أولاً تثبيت Node.js على جهازك. بمجرد التثبيت، يمكنك استخدام مدير حزم Node (NPM) لتثبيت المترجم عالميًا عن طريق تشغيل الأمر npm i -g typescript في الطرفية الخاصة بك.

terminal
# Install TypeScript
npm install -g typescript

# Check version
tsc -v
Page 4

The Configuration File

ملف التكوين (tsconfig.json)

By running tsc --init, you generate a tsconfig.json file to manage compiler settings. Crucial options include the target (output JS version), rootDir (source folder), and outDir (compiled output).

من خلال تشغيل tsc --init، يمكنك إنشاء ملف tsconfig.json لإدارة إعدادات المترجم. تتضمن الخيارات المهمة target (إصدار JS الناتج)، و rootDir (مجلد المصدر)، و outDir (المجلد الناتج المجمع).

tsconfig.json
{
  "compilerOptions": {
    "target": "ES2016",
    "module": "CommonJS",
    "rootDir": "./src",
    "outDir": "./dist",
    "noEmitOnError": true,
    "strict": true
  }
}
Page 5

Debugging TypeScript

تصحيح أخطاء TypeScript

To resolve errors, you can debug TypeScript directly in VS Code. Enable sourceMap in your config to bridge your TS code and the compiled JS, allowing you to use breakpoints effectively.

لحل الأخطاء بسهولة، يمكنك تصحيح كود TypeScript مباشرة داخل VS Code. قم بتفعيل ميزة sourceMap في ملف التكوين لربط كود TS الخاص بك بـ JavaScript المجمع، مما يسمح لك باستخدام نقاط التوقف (breakpoints) بفعالية.

launch.json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "Debug TS",
      "program": "${workspaceFolder}/src/index.ts",
      "preLaunchTask": "tsc: build - tsconfig.json",
      "outFiles": ["${workspaceFolder}/dist/**/*.js"]
    }
  ]
}

Topic 2: Core Types & Variables

Mastering primitives, arrays, tuples, and safely handling ambiguous data types.

الموضوع 2: الأنواع الأساسية والمتغيرات

إتقان الأنواع الأولية، المصفوفات، الـ tuples، والتعامل الآمن مع أنواع البيانات الغامضة.

Page 1

Type Inference & Primitives

استنتاج الأنواع والأنواع الأولية

TypeScript enhances traditional primitives like numbers, strings, and booleans. With "Type Inference", if you initialize a variable—like let sales = 123;—the compiler automatically assigns the number type.

تعزز TypeScript الأنواع الأولية التقليدية مثل الأرقام والنصوص والقيم المنطقية. بفضل ميزة "استنتاج النوع" (Type Inference)، إذا قمت بتهيئة متغير - مثل let sales = 123; - فإن المترجم ذكي بما يكفي لتخمين وتعيين نوع number له تلقائيًا.

inference.ts
let count = 5; // Inferred as number
// count = "five"; // Error

let price: number = 19.99; // Explicit
let productName = "Coffee"; // Inferred
Page 2

The Danger of the "any" Type

خطر النوع "any"

Declaring a variable without initializing it results in the any type, which neutralizes type safety. Using noImplicitAny in your config forces the compiler to flag these as errors.

يؤدي التصريح عن متغير دون تهيئته إلى تعيين النوع any له، مما يعني أنه يمكنه قبول أي نوع بيانات. استخدام النوع any يبطل الفائدة الأساسية لـ TypeScript، لذا يفضل تفعيل إعداد noImplicitAny لمنع هذه الحالات.

any.ts
let level; // Type is 'any'
level = 1;
level = "Easy"; // No error, but dangerous!

function render(document: any) {
  console.log(document);
}
Page 3

Typed Arrays

المصفوفات المحددة النوع

In TypeScript, you can restrict arrays to specific types like number[]. This provides powerful autocompletion (IntelliSense) when manipulating array elements.

في TypeScript، يمكنك تقييد المصفوفات بنوع معين مثل number[]. من خلال تحديد نوع المصفوفة، يكتسب محرر الكود سياقًا، مما يسمح له بتقديم اقتراحات إكمال تلقائي قوية (IntelliSense) عند التعامل مع عناصر تلك المصفوفة.

arrays.ts
let numbers: number[] = [1, 2, 3];
// numbers.push('4'); // Error

numbers.forEach(n => n.toFixed(2)); // Autocomplete works!
Page 4

Tuples: Fixed-Length Arrays

الـ Tuples: مصفوفات ثابتة الطول

A Tuple is an array with a fixed length and explicit types for each position, perfect for key-value pairs like [number, string].

الـ Tuple هو هيكل جديد في TypeScript: مصفوفة ذات طول ثابت دائمًا، حيث يكون لكل موضع محدد نوع صريح. إنها مثالية لتمثيل أزواج القيم مثل معرف المستخدم واسم المستخدم [number, string].

tuples.ts
let user: [number, string] = [1, 'Moataz'];
// user = ['Moataz', 1]; // Error: order matters

user[1].toUpperCase(); // Safe access
Page 5

Enums

التعدادات (Enums)

Enums represent a logical grouping of related constants. Using const enum significantly optimizes the generated JavaScript.

تمثل الـ Enums مجموعة منطقية من الثوابت المرتبطة، مثل أحجام القمصان. باستخدام الكلمة المفتاحية const enum، يقوم المترجم بتحسين ملف JavaScript الناتج بشكل كبير، مما يؤدي إلى كود أكثر إيجازًا.

enums.ts
const enum Size { Small = 1, Medium, Large };
let mySize: Size = Size.Medium; // Value is 2

console.log(mySize);

Topic 3: Functions & Objects

Writing safe functions and establishing robust object shapes.

الموضوع 3: الدوال والكائنات

كتابة دوال آمنة وتحديد أشكال كائنات قوية.

Page 1

Typing Functions Properly

تحديد أنواع الدوال بشكل صحيح

Functions should be tightly annotated, defining both parameter types and the return type. Use void for functions that return nothing.

يجب تحديد أنواع الدوال بدقة، مع تعريف أنواع المعاملات (parameters) ونوع القيمة الراجعة. استخدم الكلمة المفتاحية void للدوال التي لا ترجع أي قيمة.

functions.ts
function calculateTax(income: number): number {
  if (income < 50_000) return income * 1.2;
  return income * 1.4;
}

function log(message: string): void {
  console.log(message);
}
Page 2

Optional & Default Parameters

المعاملات الاختيارية والافتراضية

Designate optional parameters with ? or use default values in the function signature for flexibility.

يمكنك تحديد المعاملات الاختيارية باستخدام علامة الاستفهام (?) أو توفير قيم افتراضية داخل تعريف الدالة لضمان المرونة.

params.ts
// Optional parameter 'tax'
function getIncome(income: number, tax?: number) {
  return income - (tax || 0);
}

// Default parameter
function greet(name: string, title = 'Mr.') {
  return `${title} ${name}`;
}
Page 3

Strict Compiler Checks

فحوصات المترجم الصارمة

Flags like noUnusedLocals and noUnusedParameters act as cleanup tools, while noImplicitReturns ensures safety across all logical paths.

تعمل خيارات مثل noUnusedLocals و noUnusedParameters كأدوات تنظيف تلقائية، بينما يضمن noImplicitReturns إرجاع قيمة صالحة في كل مسار منطقي.

strict.ts
// With noImplicitReturns: true
function check(value: number): string {
  if (value > 0) return "Positive";
  // Error: Function lacking return at end
}
Page 4

Object Shapes & Properties

أشكال الكائنات وخصائصها

TypeScript locks down the "shape" of objects. Use ? for optional properties and readonly to prevent overwriting critical data.

تقوم TypeScript بتثبيت "شكل" الكائن بدقة. استخدم العلامة الاختيارية (?) للخصائص غير الإلزامية، والكلمة المفتاحية readonly لمنع تعديل البيانات الحساسة لاحقًا.

objects.ts
let employee: {
  readonly id: number,
  name: string,
  fax?: string
} = { id: 1, name: 'Moataz' };

// employee.id = 2; // Error: readonly
Page 5

Defining Object Methods

تعريف طرق الكائنات (Methods)

Annotate methods inside objects by defining their signature, parameter types, and return values to ensure consistent operational behavior.

لا تقتصر الكائنات على البيانات فحسب؛ بل تحتوي على وظائف (methods). عند تحديد نوع وظيفة داخل كائن، فإنك تحدد أنواع المعاملات ونوع القيمة الراجعة لضمان التوافق التام.

methods.ts
let user = {
  id: 1,
  name: 'Moataz',
  retire: (date: Date) => {
    console.log(date);
  }
};

Topic 4: Advanced Type Manipulation

Constructing complex logic using unions, intersections, and dynamic type resolution.

الموضوع 4: التلاعب المتقدم بالأنواع

بناء منطق معقد باستخدام الاتحادات، التقاطعات، وحل الأنواع الديناميكي.

Page 1

Type Aliases

الأسماء المستعارة للأنواع (Type Aliases)

Use the type keyword to define custom identifiers for complex structures, improving code reuse and clarity.

استخدم الكلمة المفتاحية type لتعريف معرفات مخصصة للهياكل المعقدة، مما يحسن إعادة استخدام الكود ووضوحه.

aliases.ts
type Employee = {
  readonly id: number,
  name: string,
  retire: (date: Date) => void
};

let worker: Employee = { id: 1, name: 'John', retire: (d) => {} };
Page 2

Union and Intersection Types

أنواع الاتحاد والتقاطع

Unions (|) allow multiple types, while Intersections (&) combine multiple types into one.

تسمح الاتحادات (|) بمتغير يقبل أنواعًا متعددة، بينما تدمج التقاطعات (&) عدة أنواع في كيان واحد.

unions.ts
// Union
function kgToLbs(weight: number | string): number {
  if (typeof weight === 'number') return weight * 2.2;
  return parseInt(weight) * 2.2;
}

// Intersection
type Draggable = { drag: () => void };
type Resizable = { resize: () => void };
type UIWidget = Draggable & Resizable;
Page 3

Literal Types

الأنواع الحرفية (Literal Types)

Constraint variables to exact specific values (e.g., 'cm' | 'inch') for maximum security and clarity.

تقييد المتغيرات بقيم محددة تمامًا (مثل 'cm' | 'inch') لضمان أقصى قدر من الأمان والوضوح في الكود.

literals.ts
type Quantity = 50 | 100;
let stock: Quantity = 50; // Valid
// stock = 75; // Error

type Metric = 'cm' | 'inch';
Page 4

Nullables & Optional Chaining

القيم القابلة للعدم والربط الاختياري

Handle null/undefined safely using strictNullChecks and Optional Chaining (?.) to prevent crashes.

تعامل مع القيم الفارغة بأمان باستخدام strictNullChecks والربط الاختياري (?.) لمنع توقف التطبيق المفاجئ.

nullable.ts
function greet(name: string | null) {
  console.log(name?.toUpperCase()); // Optional Chaining
}

let customer = { birthday: new Date() };
console.log(customer?.birthday?.getFullYear());
Page 5

Interfaces & Structural Typing

الواجهات والأنواع الهيكلية

Use interface to define object shapes. TypeScript uses "Structural Typing" to check compatibility based on fields.

استخدم interface لتحديد أشكال الكائنات. تعتمد TypeScript على "الأنواع الهيكلية" للتحقق من التوافق بناءً على الحقول الموجودة.

interfaces.ts
interface Calendar {
  name: string;
  addEvent(event: string): void;
}

class GoogleCalendar implements Calendar {
  constructor(public name: string) {}
  addEvent(event: string) { console.log(event); }
}

Topic 5: Ecosystem & Architecture

Integrating TypeScript into the broader programming ecosystem and making architectural choices.

الموضوع 5: النظام البيئي والمعمارية

Page 1

Gradual Adoption Strategy

استراتيجية الاعتماد التدريجي

Adopt TypeScript progressively by enabling allowJs: true. Rename files from .js to .ts sequentially.

يمكن اعتماد TypeScript تدريجيًا من خلال تفعيل خيار allowJs: true. قم بتغيير أسماء الملفات من .js إلى .ts بالتتابع لدمج الأمان تدريجيًا.

check.js
// @ts-check
/** @type {number} */
let age = 30;
// age = 'thirty'; // TS will warn here even in JS
Page 2

TypeScript vs. Python Architecture

معمارية TypeScript مقابل Python

TypeScript dominates frontend and I/O tasks, while Python excels in CPU-heavy tasks and data processing. High-performing teams often use both.

تهيمن TypeScript على واجهات المستخدم والمهام كثيفة المدخلات/المخرجات، بينما تتفوق Python في المهام الثقيلة ومعالجة البيانات. غالبًا ما تستخدم الفرق عالية الأداء كليهما.

bridge.ts
// TS Interface shared with Python API
interface UserProfile {
  id: string;
  preferences: string[];
}
Page 3

AI and Data Workflows

الذكاء الاصطناعي وسير عمل البيانات

Python remains the standard for AI due to mature libraries like TensorFlow and PyTorch, which TypeScript currently lacks.

تظل Python هي المعيار للذكاء الاصطناعي بسبب المكتبات الناضجة مثل TensorFlow و PyTorch، وهو ما تفتقر إليه TypeScript حاليًا في هذا المجال.

ai-bridge.py
# Python handles the heavy lifting
import torch
model = torch.load('model.pth')
# TS frontend just consumes the JSON result

Real-World CMS Integration (Strapi)

التكامل مع أنظمة إدارة المحتوى (Strapi)

TypeScript stabilizes enterprise development by syncing backend schemas to frontend interfaces, preventing runtime crashes.

export interface Article {

The Speculative "C" Equivalent

المقابل النظري في لغة "C"

Some compare TypeScript augmenting JS to Objective-C or D augmenting C, adding strict constraints and modern features.

speculative.cpp
// C++ with Type Safety analogues
auto name = std::string("TS");
// Similar to: let name = "TS";
