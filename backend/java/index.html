☕ What is Java?

Java is a class-based, object-oriented language created by Sun Microsystems in 1995. It follows the "Write Once, Run Anywhere" principle — runs on any device with a JVM.

🌍 Platform Independent

Compiled to bytecode, runs on any OS via the JVM.

🔒 Strongly Typed

All types are checked at compile time — fewer runtime bugs.

🏗 OOP First

Everything is a class. Great for large, structured applications.

🚀 Enterprise Ready

Used by Netflix, Amazon, LinkedIn, and millions of Android apps.

⚙️ Setup

Install the JDK from adoptium.net or oracle.com/java, then verify:

# Check versions
java -version
javac -version

# Compile and run
javac Main.java
java Main
💡 Use an IDE like IntelliJ IDEA (recommended) or VS Code with the Java Extension Pack for the best experience.

👋 Hello World

Every Java program must have a class. The entry point is public static void main(String[] args).

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java! 🎉");
    }
}

📦 Variables

Java is statically typed — you must declare the type. Use var (Java 10+) for type inference.

public class Main {
    public static void main(String[] args) {
        String  name  = "Alice";
        int     age   = 25;
        double  price = 9.99;
        boolean ready = true;

        // var (Java 10+)
        var city = "Cairo";

        // Constants
        final int MAX = 100;

        System.out.println(name + " is " + age);
    }
}

🔀 Control Flow

// if / else
int age = 20;
if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}

// for loop
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

// while loop
int x = 0;
while (x < 3) { x++; }

// switch (modern style)
String day = "Monday";
switch (day) {
    case "Monday"  -> System.out.println("Start of week");
    case "Friday"  -> System.out.println("Weekend soon!");
    default        -> System.out.println("Midweek");
}

🧩 Methods

public class Main {

    // Method with return value
    static String greet(String name) {
        return "Hello, " + name + "!";
    }

    // Overloaded method
    static int add(int a, int b)          { return a + b; }
    static double add(double a, double b) { return a + b; }

    public static void main(String[] args) {
        System.out.println(greet("Bob"));
        System.out.println(add(3, 4));
        System.out.println(add(1.5, 2.5));
    }
}

📋 Arrays & Lists

// Array (fixed size)
int[] nums = {1, 2, 3, 4, 5};
System.out.println(nums[0]);    // 1
System.out.println(nums.length); // 5

// for-each loop
for (int n : nums) {
    System.out.println(n);
}

// ArrayList (dynamic)
import java.util.ArrayList;
ArrayList<String> list = new ArrayList<>();
list.add("Java");
list.add("Go");
list.remove("Go");
System.out.println(list.get(0)); // Java

🏗 OOP & Classes

public class Car {
    // Fields
    String brand;
    int    year;

    // Constructor
    public Car(String brand, int year) {
        this.brand = brand;
        this.year  = year;
    }

    // Method
    public String info() {
        return brand + " (" + year + ")";
    }
}

// Usage
Car c = new Car("Toyota", 2023);
System.out.println(c.info()); // Toyota (2023)

🔗 Inheritance

public class Animal {
    String name;
    public void speak() {
        System.out.println(name + " makes a sound");
    }
}

public class Dog extends Animal {
    public Dog(String name) { this.name = name; }

    // Override parent method
    @Override
    public void speak() {
        System.out.println(name + " says: Woof!");
    }
}

Dog d = new Dog("Rex");
d.speak(); // Rex says: Woof!

🔌 Interfaces

interface Drawable {
    void draw(); // abstract by default
}

public class Circle implements Drawable {
    public void draw() {
        System.out.println("Drawing a circle ◯");
    }
}

Drawable d = new Circle();
d.draw();
💡 Use interfaces to define contracts. A class can implement multiple interfaces but extend only one class.

❌ Exception Handling

public class Main {
    public static void main(String[] args) {
        try {
            int result = 10 / 0; // ArithmeticException
        } catch (ArithmeticException e) {
            System.out.println("Error: " + e.getMessage());
        } finally {
            System.out.println("Always runs");
        }
    }

    // Throw custom exception
    static void checkAge(int age) throws Exception {
        if (age < 0) throw new Exception("Age can't be negative");
    }
}

⚡ Streams & Lambdas

Java 8+ introduced Streams and Lambdas for functional-style programming.

import java.util.*;
import java.util.stream.*;

List<Integer> nums = List.of(1, 2, 3, 4, 5);

// Filter + Map + Collect
List<Integer> result = nums.stream()
    .filter(n -> n % 2 == 0)   // keep evens
    .map(n -> n * 10)            // multiply by 10
    .collect(Collectors.toList());

System.out.println(result); // [20, 40]

// Sum
int sum = nums.stream().mapToInt(Integer::intValue).sum();

// Lambda as variable
Runnable r = () -> System.out.println("Running!");
r.run();
