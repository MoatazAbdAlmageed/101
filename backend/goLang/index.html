Go — Zero to Hero

A complete beginner's guide to the Go programming language

🚀 What is Go?

Go (Golang) is an open-source programming language created by Google in 2009. It is fast, simple, and built for modern software — especially backend services, APIs, and cloud tools.

⚡ Fast

Compiles to native machine code. Near C-level performance.

🧵 Concurrent

Built-in goroutines make parallel programming easy.

📦 Simple

Very small syntax. Easy to read, easy to maintain.

🔒 Safe

Strong typing and garbage collection prevent many bugs.

Used by: Docker, Kubernetes, Terraform, GitHub CLI, Cloudflare, Uber.

⚙️ Installation

Download from go.dev/dl and install. Then verify:

# Check Go version
go version
# Output: go version go1.22 windows/amd64

# Create a new project
mkdir myapp
cd myapp
go mod init myapp
💡 go mod init creates a go.mod file — like package.json in Node.js.

👋 Hello World

Every Go file belongs to a package. The entry point is always func main().

package main

import "fmt"

func main() {
    fmt.Println("Hello, Go! 🎉")
}
# Run it
go run main.go

# Build it
go build -o myapp main.go

📦 Variables

Go has two ways to declare variables — with var or the shorthand :=.

package main

import "fmt"

func main() {
    // Full declaration
    var name string = "Alice"
    var age  int    = 25

    // Short declaration (most common)
    city    := "Cairo"
    isReady := true

    fmt.Println(name, age, city, isReady)

    // Constants
    const Pi = 3.14159
    fmt.Println(Pi)
}

🔀 Control Flow

// if / else
age := 20
if age >= 18 {
    fmt.Println("Adult")
} else {
    fmt.Println("Minor")
}

// for loop (Go's only loop)
for i := 0; i < 5; i++ {
    fmt.Println(i)
}

// while-style loop
x := 0
for x < 3 {
    x++
}

// switch
day := "Monday"
switch day {
case "Monday":
    fmt.Println("Start of week")
case "Friday":
    fmt.Println("Weekend soon!")
default:
    fmt.Println("Midweek")
}

🧩 Functions

Go functions can return multiple values — a very powerful feature.

// Basic function
func greet(name string) string {
    return "Hello, " + name
}

// Multiple return values
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("cannot divide by zero")
    }
    return a / b, nil
}

func main() {
    result, err := divide(10, 2)
    if err != nil {
        fmt.Println("Error:", err)
    } else {
        fmt.Println(result) // 5
    }
}

📋 Arrays & Slices

Arrays have fixed size. Slices are dynamic and much more common.

// Array (fixed size)
var arr [3]int = [3]int{1, 2, 3}

// Slice (dynamic)
nums := []int{10, 20, 30}
nums = append(nums, 40)
fmt.Println(nums)        // [10 20 30 40]
fmt.Println(nums[1])     // 20
fmt.Println(nums[1:3])   // [20 30]

// Iterate with range
for i, v := range nums {
    fmt.Println(i, v)
}

🗺 Maps

Maps are key-value stores — like objects in JS or dicts in Python.

person := map[string]string{
    "name": "Bob",
    "city": "Cairo",
}

// Access
fmt.Println(person["name"])

// Add / Update
person["job"] = "Developer"

// Delete
delete(person, "city")

// Check if key exists
val, ok := person["city"]
if !ok {
    fmt.Println("Key not found")
}

🏗 Structs

Structs are Go's way of defining custom types — like classes but simpler.

type User struct {
    Name  string
    Age   int
    Email string
}

// Method on struct
func (u User) Greet() string {
    return "Hi, I'm " + u.Name
}

func main() {
    u := User{Name: "Alice", Age: 30, Email: "alice@example.com"}
    fmt.Println(u.Greet())
    fmt.Println(u.Age)
}

📍 Pointers

A pointer holds the memory address of a value. Use & to get the address, * to read the value.

x := 42
p := &x          // p is a pointer to x

fmt.Println(*p)  // 42 — dereference pointer
*p = 100         // change value via pointer
fmt.Println(x)   // 100

// Pointer in function (modify original)
func double(n *int) {
    *n = *n * 2
}
double(&x)
fmt.Println(x) // 200

⚡ Goroutines & Channels

Goroutines are lightweight threads. Use the go keyword to run code concurrently.

import (
    "fmt"
    "sync"
)

func worker(id int, wg *sync.WaitGroup) {
    defer wg.Done()
    fmt.Printf("Worker %d done\n", id)
}

func main() {
    var wg sync.WaitGroup
    for i := 1; i <= 3; i++ {
        wg.Add(1)
        go worker(i, &wg)
    }
    wg.Wait() // wait for all goroutines
}

// Channels — communicate between goroutines
ch := make(chan int)
go func() { ch <- 42 }()
val := <-ch
fmt.Println(val) // 42

❌ Error Handling

Go has no exceptions. Functions return an error value and you check it explicitly.

import (
    "errors"
    "fmt"
)

func getAge(age int) (int, error) {
    if age < 0 {
        return 0, errors.New("age cannot be negative")
    }
    return age, nil
}

func main() {
    age, err := getAge(-5)
    if err != nil {
        fmt.Println("Error:", err)
        return
    }
    fmt.Println("Age:", age)
}
💡 Always handle errors! Ignoring them with _ is bad practice in production code.
