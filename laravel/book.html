1. Introduction to Laravel & MVC

Intro

Laravel is a free, open-source PHP framework designed to make web development fast, secure, and enjoyable. It uses the MVC (Model-View-Controller) architectural pattern.

Explanation

The MVC pattern divides an application into three interconnected parts:
- Model: Handles data and database logic.
- View: What the user sees (HTML/CSS).
- Controller: The brain that takes user requests, fetches data from the Model, and passes it to the View.

Examples & Real-World Use Cases

Example 1: The Restaurant Analogy

Think of a restaurant. You (the user) place an order with the waiter (Controller). The waiter gives the order to the kitchen (Model) which prepares the food (Data). The waiter then brings the finished plate (View) back to your table.

Example 2: Directory Structure

In Laravel, Models live in app/Models, Controllers in app/Http/Controllers, and Views in resources/views.

Example 3: Real-World E-commerce

When you click "View Product", the ProductController asks the Product Model for the item's price and details. It then sends this data to the product.blade.php View to be displayed on your screen.

Mini Exercise

Question: If you want to change the color of a button on your website, which part of MVC do you edit?

Show Answer

The View. The View handles all user interface elements, including HTML and CSS styling.

Summary

Laravel uses the MVC structure to keep code organized. Models handle data, Views handle display, and Controllers manage the logic linking them together.

الشرح (Explanation)

يقوم نمط MVC بتقسيم التطبيق إلى ثلاثة أجزاء مترابطة:

أمثلة وحالات استخدام واقعية

تخيل أنك في مطعم. أنت (المستخدم) تقدم طلبك للنادل (Controller). النادل ينقل الطلب إلى المطبخ (Model) الذي يجهز الطعام (البيانات). ثم يحضر النادل الطبق الجاهز (View) إلى طاولتك.

في لارافيل، توجد النماذج في app/Models، ووحدات التحكم في app/Http/Controllers، وعروض واجهة المستخدم في resources/views.

2. Routing & Blade Views

Intro

Routing is how Laravel connects URLs (like /about) to specific code. Blade is Laravel's powerful templating engine used to create dynamic HTML pages.

Explanation

All web routes are defined in routes/web.php. When a user visits a URL, Laravel finds the matching route and executes its function, usually returning a Blade view (which allows writing PHP inside HTML cleanly).

Examples & Real-World Use Cases

Example 1: A Basic Route

Returning a simple text string when visiting a URL. 

Route::get('/hello', function () {
    return 'Hello, World!';
});

Example 2: Returning a Blade View

Instead of text, we return an HTML file located at resources/views/welcome.blade.php. 

Route::get('/', function () {
    return view('welcome');
});

Example 3: Passing Data to Blade (Real World)

Passing an array of user tasks to a view, then using a Blade @foreach loop to display them dynamically. 

// In web.php
Route::get('/tasks', function () {
    $tasks = ['Learn Laravel', 'Build an App'];
    return view('tasks', ['tasks' => $tasks]);
});

// In tasks.blade.php
<ul>
    @foreach ($tasks as $task)
        <li>{{ $task }}</li>
    @endforeach
</ul>

Mini Exercise

Task: Write a route for the URL /contact that returns a view named contact.

Show Answer 
Route::get('/contact', function () {
    return view('contact');
});

Summary

Routes act as the entry points for your app. They capture the URL and direct it to a Controller or a Blade View, allowing you to easily generate dynamic web pages.

2. التوجيه (Routing) وعروض Blade

مقدمة (Intro)

التوجيه هو كيفية ربط لارافيل للروابط (مثل /about) بكود برمجي معين. Blade هو محرك القوالب القوي في لارافيل المستخدم لإنشاء صفحات HTML ديناميكية.

الشرح (Explanation)

يتم تعريف جميع مسارات الويب في ملف routes/web.php. عندما يزور المستخدم رابطاً، يبحث لارافيل عن المسار المطابق وينفذ وظيفته، وعادةً ما يقوم بإرجاع عرض Blade (والذي يسمح بكتابة PHP داخل HTML بشكل نظيف).

أمثلة وحالات استخدام واقعية

مثال 1: مسار بسيط

إرجاع نص بسيط عند زيارة رابط.

    return 'Hello, World!';

مثال 2: إرجاع عرض Blade

بدلاً من النص، نقوم بإرجاع ملف HTML موجود في resources/views/welcome.blade.php.

    return view('welcome');

مثال 3: تمرير البيانات إلى Blade (استخدام واقعي)

3. Databases & Eloquent ORM

Intro

Interacting with databases using raw SQL can be tedious. Laravel features Eloquent ORM, which allows you to interact with your database like standard PHP objects.

Explanation

ORM stands for Object-Relational Mapper. In Eloquent, each database table has a corresponding "Model" class. For example, a users table is controlled by a User model. You can fetch, insert, update, and delete records without writing SQL.

Examples & Real-World Use Cases

Example 1: Fetching All Records

To get all users from the database, you simply call the all() method on the Model. 

$users = User::all();

Example 2: Filtering Data (Real World)

Finding specific records, such as finding all "active" users who registered recently. 

$activeUsers = User::where('status', 'active')
                   ->orderBy('created_at', 'desc')
                   ->get();

Example 3: Inserting New Data

Creating a new database row using an object-oriented approach. 

$user = new User();
$user->name = 'John Doe';
$user->email = 'john@example.com';
$user->save(); // This inserts the record into the DB

Mini Exercise

Task: Using Eloquent, how would you find a single user with the ID of 5?

Show Answer 
$user = User::find(5);

Summary

Eloquent ORM replaces complex SQL queries with beautiful, readable PHP syntax. It maps your database tables to PHP classes seamlessly, making data manipulation incredibly fast and safe.

3. قواعد البيانات و Eloquent ORM

مقدمة (Intro)

التعامل مع قواعد البيانات باستخدام استعلامات SQL الخام قد يكون مرهقًا. يتميز لارافيل بوجود Eloquent ORM، والذي يتيح لك التفاعل مع قاعدة بياناتك وكأنها كائنات PHP عادية.

الشرح (Explanation)

يرمز ORM إلى "Object-Relational Mapper". في Eloquent، يحتوي كل جدول في قاعدة البيانات على فئة "نموذج" (Model) تقابله. على سبيل المثال، يتم التحكم في جدول users بواسطة نموذج User. يمكنك جلب، إدراج، تحديث، وحذف السجلات دون كتابة أوامر SQL.

أمثلة وحالات استخدام واقعية

مثال 1: جلب جميع السجلات

للحصول على جميع المستخدمين من قاعدة البيانات، ببساطة تقوم باستدعاء دالة all() على النموذج. 

$users = User::all();

مثال 2: تصفية البيانات (استخدام واقعي)

البحث عن سجلات محددة، مثل العثور على جميع المستخدمين الـ "نشطين" الذين سجلوا مؤخرًا. 

$activeUsers = User::where('status', 'active')
                   ->orderBy('created_at', 'desc')
                   ->get();

مثال 3: إدراج بيانات جديدة

إنشاء صف جديد في قاعدة البيانات باستخدام أسلوب الكائنات (OOP). 

$user = new User();
$user->name = 'John Doe';
$user->email = 'john@example.com';
$user->save(); // This inserts the record into the DB

الخلاصة (Summary)

يستبدل Eloquent ORM استعلامات SQL المعقدة بصيغ برمجة PHP جميلة وسهلة القراءة. فهو يربط جداول قاعدة بياناتك بفئات PHP بسلاسة، مما يجعل معالجة البيانات سريعة وآمنة بشكل لا يصدق.
