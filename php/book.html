Topic 1: PHP Fundamentals

1.1 What is PHP?

Welcome to the world of backend web development! PHP is a highly popular, open-source, server-side scripting language primarily used for building dynamic websites. Originally created by Rasmus Lerdorf in 1993, the acronym originally stood for "Personal Home Page," but today it stands for the recursive acronym "PHP: Hypertext Preprocessor",.

Unlike client-side languages like JavaScript that run in the user's browser, PHP code executes on the web server. The server processes the script and sends plain HTML back to the client's browser, meaning visitors never see your underlying logic. Because of its immense flexibility and shallow learning curve, PHP powers approximately 80% of the web, including giants like Facebook, Wikipedia, and WordPress,.

1.2 Setting Up Your Development Environment

To write and execute PHP, you cannot simply open a file in your browser. You need a server environment that includes a PHP parser, a web server (like Apache or Nginx), and a database.

Practical Action:

For beginners, the easiest way to get started is by installing an all-in-one local server package such as XAMPP or MAMP,. XAMPP securely bundles Apache, MySQL (MariaDB), and PHP together for Windows, Mac, or Linux.

Once installed, you can use a code editor—like Visual Studio Code or PhpStorm—to write your scripts. Save your files with a .php extension in your server's designated "document root" folder (e.g., htdocs for XAMPP) to view them locally,.

Page 2

1.3 Basic Syntax & "Hello World"

PHP can be seamlessly embedded directly into HTML documents,. To tell the server to process a section of code as PHP, you enclose it within standard delimiters: <?php and ?>. 

<!DOCTYPE html>
<html>
<body>

    <h1>My First PHP Page</h1>
    <?php
        // This is a single-line comment in PHP
        echo "Hello, World!";
    ?>

</body>
</html>

In this example, the echo statement is a built-in command used to output text to the browser. Every distinct instruction in PHP must be terminated with a semicolon (;).

1.4 Variables and Data Types

Variables are used to store data in memory. In PHP, every variable name must begin with a dollar sign ($) and is case-sensitive,. PHP is considered a loosely typed language, meaning you do not have to explicitly declare the data type when creating a variable; PHP automatically interprets it based on the assigned value,. 

<?php
    $greeting = "Hello, Learner!"; // String
    $userAge = 25;               // Integer
    $price = 19.99;              // Float
    $isLoggedIn = true;          // Boolean
    
    // Combining strings and variables (Interpolation)
    echo "$greeting You are $userAge years old.";
?>

PHP supports primitive types (integers, floats, strings, booleans) and complex types (arrays, objects).

Topic 2: Control Flow & Logic

2.1 The Power of Decision Making

Static websites display the same content to every user. Dynamic applications, however, can make decisions and execute different blocks of code based on user inputs or conditions. This is achieved using control flow structures.

PHP provides several operators for logic: Comparison operators (like == for equality, > for greater than) and Logical operators (like && for AND, || for OR). Understanding these is critical before building decision-making structures.

Page 6

2.2 If, Else, and Elseif

The if statement is the most fundamental control structure. It evaluates a condition, and if that condition is true, executes the enclosed block of code. 

<?php
    $temperature = 15;

    if ($temperature > 30) {
        echo "It's a hot day!";
    } elseif ($temperature >= 15) {
        echo "The weather is pleasant.";
    } else {
        echo "It's cold outside.";
    }
?>

You can chain multiple conditions together using elseif, providing a robust way to handle multiple potential scenarios.

Page 7

2.3 Switch and Match Expressions

When you have a single variable that could evaluate to many different specific values, chaining if/elseif statements becomes messy. Historically, developers used the switch statement. However, modern PHP 8 introduced the Match Expression. 

<?php
    // PHP 8+ Match Expression
    $statusCode = 404;

    $message = match ($statusCode) {
        200 => 'Success',
        404 => 'Page Not Found',
        500 => 'Server Error',
        default => 'Unknown Status',
    };
    
    echo $message; // Outputs: Page Not Found
?>

Match expressions are concise, return a value directly, and use strict type comparisons, making them much safer and cleaner than older switch statements,.

Page 8

2.4 Loops: While, Do-While, and For

Loops allow you to repeat a block of code multiple times. PHP supports several loops:

  • While loop: Executes code as long as a condition is true,.
  • Do-While loop: Executes the code at least once before checking the condition.
  • For loop: Best used when you know exactly how many times the script should run. 
<?php
    // A simple for loop
    for ($i = 1; $i <= 5; $i++) {
        echo "Iteration number: $i <br>";
    }
?>

Topic 3: Functions & Arrays

3.1 Organizing Code with Functions

As your code grows, writing everything in a single sequence becomes unmanageable. Functions allow for modularity by grouping instructions together under a reusable name,.

PHP comes with thousands of built-in functions for manipulating strings, math, dates, and more. For example, strlen($string) returns the length of a string, and str_replace() replaces characters,. However, the real power comes from defining your own functions.

Page 11

3.2 User-Defined Functions

To create a function, you use the function keyword, followed by an identifier and parentheses containing any required parameters. Modern PHP also allows you to specify expected data types and return types, enforcing strict, error-free code. 

<?php
    // Declaring a function with typed parameters and a return type
    function calculateTotal(float $price, int $quantity): float {
        return $price * $quantity;
    }

    $total = calculateTotal(15.50, 4);
    echo "The total is $" . $total;
?>

PHP also supports Anonymous functions (closures) and Arrow functions (fn() => ...) for quick, inline operations,.

Page 12

3.3 Mastering Arrays

Arrays are complex data structures that allow you to store multiple values in a single variable,. PHP supports two main types of arrays:

  • Indexed Arrays: Ordered lists where each item is assigned a numeric index (starting at 0).
  • Associative Arrays: Key-value pairs where you assign custom string keys to values, acting much like a dictionary or JSON object. 
<?php
    // Associative Array
    $user = [
        "name" => "Alice",
        "role" => "Admin",
        "active" => true
    ];
    
    echo $user["name"]; // Outputs: Alice
?>
Page 13

3.4 Iterating Over Arrays

The most effective way to loop through an array in PHP is using the foreach loop. It automatically handles the internal pointer, visiting every element from start to finish. 

<?php
    $scores = ["Math" => 95, "Science" => 88, "History" => 92];

    foreach ($scores as $subject => $score) {
        echo "Subject: $subject | Score: $score <br>";
    }
?>

PHP also provides powerful functional programming tools like array_map() and array_filter() for modifying array elements without writing manual loops.

Topic 4: Object-Oriented Programming

4.1 Moving Beyond Procedural Code

In its early days, PHP was purely procedural. With PHP 5, robust Object-Oriented Programming (OOP) was introduced, elevating PHP to match languages like Java and Python,. OOP revolves around grouping related data and actions together into distinct entities called objects.

OOP relies on four main pillars: Encapsulation (hiding data), Inheritance (sharing behaviors), Abstraction (defining blueprints), and Polymorphism (overriding behaviors),. Following these principles makes large codebases vastly easier to read, test, and maintain,.

Page 16

4.2 Classes and Objects

A Class is a blueprint or template. An Object is a specific, instantiated instance of that class. Classes define Properties (variables inside the class) and Methods (functions inside the class),. 

<?php
    class User {
        // Properties
        public $name;
        
        // Methods
        public function sayHello() {
            echo "Hello, my name is " . $this->name;
        }
    }

    // Instantiating an object
    $person = new User();
    $person->name = "David";
    $person->sayHello();
?>

Notice the pseudo-variable $this. It is used inside a class to refer to the current object instance itself.

Page 17

4.3 Constructors & Access Modifiers

A Constructor (__construct) is a "magic method" automatically called the moment an object is instantiated. It is used to initialize the object's properties.

To practice encapsulation, you should protect an object's internal state using access modifiers: public (accessible everywhere), private (accessible only within the class itself), and protected (accessible in the class and its children),. 

<?php
    class BankAccount {
        private float $balance; // Cannot be accessed directly from outside

        public function __construct(float $initialBalance) {
            $this->balance = $initialBalance;
        }

        public function getBalance(): float {
            return $this->balance;
        }
    }
?>
Page 18

4.4 Inheritance

Inheritance allows a new class (the child) to take on the properties and methods of an existing class (the parent) using the extends keyword. This drastically reduces code duplication. 

<?php
    class Animal {
        public function eat() {
            echo "Munch munch...";
        }
    }

    class Dog extends Animal {
        public function bark() {
            echo "Woof!";
        }
    }

    $myDog = new Dog();
    $myDog->eat();  // Inherited from Animal
    $myDog->bark(); // Defined in Dog
?>

Child classes can also override parent methods by declaring a method with the identical name.

Object-Oriented Programming shifts your thinking from "how to write a sequence of actions" to "how data entities relate and interact." It's essential for writing robust, modern PHP applications (especially when working with frameworks like Laravel).

Topic 5: Databases & Application Security

5.1 Database Integration

To build truly dynamic applications, you must be able to store, retrieve, update, and delete information dynamically (CRUD operations). PHP is universally praised for its straightforward integration with relational databases, particularly MySQL,.

Rather than utilizing outdated native driver methods, modern PHP developers leverage PDO (PHP Data Objects). PDO offers a consistent, object-oriented abstraction layer regardless of the database you are using (MySQL, PostgreSQL, etc.),.

Page 21

5.2 Querying Safely with PDO

One of the greatest security risks in web development is SQL Injection—where a hacker inputs malicious SQL commands into a form to corrupt or steal your database contents.

To prevent this, you must never trust user input. You should always use Prepared Statements when querying your database. Prepared statements securely separate the query structure from the user-provided data,. 

<?php
    // $pdo is an active PDO connection instance
    $username = $_POST['username']; // Raw user input
    
    // The question mark acts as a safe parameter placeholder
    $stmt = $pdo->prepare('SELECT * FROM users WHERE username = ?');
    $stmt->execute([$username]);
    $user = $stmt->fetch();
?>
Page 22

5.3 Data Sanitization and XSS Prevention

Just as inputs into a database can be dangerous, outputting user data directly to an HTML page is equally risky. This can lead to Cross-Site Scripting (XSS), where malicious JavaScript is executed in your users' browsers,.

To prevent XSS, you must sanitize and escape any user-generated data before echoing it into HTML. Use built-in functions like htmlspecialchars() or strip_tags() to convert dangerous characters (like < and >) into safe HTML entities,.

Page 23

5.4 Password Hashing & Configuration

If your application has user accounts, never store passwords in plain text. Always pass user passwords through PHP's native password_hash() function, which uses strong, irreversible algorithms (like bcrypt) to securely store credentials. You can then verify logins using password_verify().

Furthermore, ensure your environment is secure. While developing, displaying errors on the screen is useful. However, in a production environment, you must configure your php.ini file to hide errors (setting display_errors = Off), so you do not leak sensitive application structure details to attackers,.

Page 24

5.5 Summary & Practice

Security is not an afterthought; it is a fundamental requirement. By using PDO prepared statements, escaping HTML output, and hashing passwords, you safeguard your applications against the vast majority of web vulnerabilities.
