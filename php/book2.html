Topic 1: PHP Fundamentals & Environment

الموضوع ١: أساسيات PHP وبيئة التطوير

Introduction & Core Concepts

PHP (Hypertext Preprocessor) is an open-source, server-side scripting language created by Rasmus Lerdorf in 1994. It currently powers nearly 80% of the web, including WordPress, Facebook, and Wikipedia.

Unlike HTML or JavaScript which run in the user's browser, PHP runs on the server. It processes data, interacts with databases, and sends plain HTML back to the client. Variables in PHP are loosely typed and always start with a dollar sign ($).

مقدمة ومفاهيم أساسية

لغة PHP هي لغة برمجة نصية مفتوحة المصدر تعمل على جانب الخادم، أنشأها راسموس ليردورف عام 1994. تشغل حالياً حوالي 80% من مواقع الويب، بما في ذلك ووردبريس وفيسبوك وويكيبيديا.

على عكس HTML أو JavaScript التي تعمل في متصفح المستخدم، تعمل PHP على الخادم (Server). تقوم بمعالجة البيانات، التفاعل مع قواعد البيانات، وإرسال كود HTML عادي للمستخدم. المتغيرات في PHP مرنة النوع وتبدأ دائماً بعلامة الدولار ($).

Practical Examples

Example 1: Hello World 
<?php
// Echo outputs text to the browser
echo "Hello, World!"; 
?>
Example 2: Variables & Types 
<?php
$name = "Alice";      // String
$age = 28;            // Integer
$isOnline = true;     // Boolean
?>
Example 3: String Interpolation 
<?php
$role = "Admin";
// Variables inside double quotes are evaluated
echo "Welcome back, $role!"; 
?>

أمثلة عملية

المثال ١: مرحباً بالعالم

Dynamic Greeting: When a user logs into a web application, PHP retrieves their name from a database and uses string interpolation to display a personalized welcome banner on the HTML dashboard.

Topic 2: Control Flow & Logic

الموضوع ٢: التحكم في سير البرنامج والمنطق

Making Decisions in Code

Dynamic applications execute different code blocks based on conditions using Control Flow structures. PHP utilizes standard if/elseif/else statements, powerful modern match expressions (introduced in PHP 8), and various loops like for and while for repetitive tasks.

اتخاذ القرارات في الكود

التطبيقات الديناميكية تنفذ أجزاء مختلفة من الكود بناءً على شروط معينة باستخدام هياكل التحكم. تستخدم PHP جمل if/elseif/else القياسية، وتعبير match الحديث والقوي (مُقدم في PHP 8)، بالإضافة إلى الحلقات التكرارية مثل for و while للمهام المتكررة.

Practical Examples

Example 1: If/Else Condition 
<?php
$stock = 5;
if ($stock > 0) {
    echo "Item is in stock!";
} else {
    echo "Out of stock.";
}
?>
Example 2: Match Expression (PHP 8) 
<?php
$status = 404;
$message = match($status) {
    200 => 'Success',
    404 => 'Not Found',
    default => 'Unknown Error'
};
echo $message;
?>
Example 3: For Loop 
<?php
// Prints numbers 1 through 3
for ($i = 1; $i <= 3; $i++) {
    echo "Number: $i <br>";
}
?>

أمثلة عملية

المثال ١: الجملة الشرطية If/Else

Topic 3: Functions & Arrays

الموضوع ٣: الدوال والمصفوفات

Organizing Code and Data

Functions group logic into reusable blocks, reducing duplication. Modern PHP allows enforcing strict data types for parameters and return values. Arrays store collections of data; PHP supports both Indexed (numbered) and Associative (key-value paired) arrays.

تنظيم الكود والبيانات

تقوم الدوال بتجميع الأوامر البرمجية في كتل قابلة لإعادة الاستخدام لتقليل التكرار. تدعم PHP الحديثة فرض أنواع بيانات صارمة للمعاملات والقيم المُرجعة. وتقوم المصفوفات بتخزين مجموعات من البيانات؛ حيث تدعم PHP المصفوفات المرقمة (Indexed) والمصفوفات الترابطية (Associative).

Practical Examples

Example 1: Typed Function 
<?php
function add(int $a, int $b): int {
    return $a + $b;
}
echo add(5, 10); // Outputs: 15
?>
Example 2: Associative Array 
<?php
$user = [
    "name" => "John",
    "email" => "john@example.com"
];
echo $user["name"]; // Outputs: John
?>
Example 3: Foreach Array Iteration 
<?php
$colors = ["Red", "Blue", "Green"];
foreach ($colors as $color) {
    echo $color . " "; 
}
?>

أمثلة عملية

المثال ١: دالة محددة الأنواع

Real-World Use Case

Shopping Cart Processing: Products added to a cart are stored as an associative array. A custom function iterates through the array to calculate the total price before tax.

Topic 4: Object-Oriented Programming

الموضوع ٤: البرمجة كائنية التوجه (OOP)

Modeling Real-World Entities

Object-Oriented Programming (OOP) allows you to group data and behavior into Classes (blueprints) and Objects (instances). Key pillars include encapsulation (using private/protected visibility modifiers) and inheritance (using extends to share behaviors).

نمذجة الكيانات الواقعية

البرمجة كائنية التوجه (OOP) تتيح لك تجميع البيانات والسلوكيات في فئات (Classes) تعمل كقوالب، وكائنات (Objects) تعمل كنسخ منها. من أهم ركائزها التغليف (عبر محددات الرؤية مثل private/protected) والوراثة (مشاركة السلوكيات عبر extends).

Practical Examples

Example 1: Class & Constructor 
<?php
class User {
    public string $name;
    public function __construct(string $n) {
        $this->name = $n;
    }
}
$user1 = new User("Tom");
?>
Example 2: Encapsulation (Private) 
<?php
class BankAccount {
    private float $balance = 0;
    public function deposit(float $amount) {
        $this->balance += $amount;
    }
}
?>
Example 3: Inheritance 
<?php
class Admin extends User {
    public function banUser() {
        echo "User banned by " . $this->name;
    }
}
?>

أمثلة عملية

المثال ١: الفئة ودالة البناء

Real-World Use Case

E-commerce Models: Developers use classes to represent concepts like Product, Cart, and Order. Complex frameworks like Laravel rely entirely on OOP principles to map objects to database tables.

Topic 5: Databases & Security

الموضوع ٥: قواعد البيانات والأمان

Storing Data Safely

Dynamic sites require databases (like MySQL). In modern PHP, we use PDO (PHP Data Objects) to connect and query safely using Prepared Statements, which prevent SQL Injection attacks. Additionally, sensitive data like passwords must always be hashed natively.

تخزين البيانات بأمان

المواقع الديناميكية تتطلب قواعد بيانات (مثل MySQL). في PHP الحديثة، نستخدم PDO للاتصال والاستعلام بأمان عبر الجمل المُجهزة (Prepared Statements)، والتي تمنع هجمات حقن SQL (SQL Injection). إضافة إلى ذلك، يجب تشفير البيانات الحساسة ككلمات المرور برمجياً.

Practical Examples

Example 1: PDO Connection 
<?php
$dsn = "mysql:host=localhost;dbname=testdb";
$pdo = new PDO($dsn, "user", "pass");
?>
Example 2: Prepared Statement 
<?php
$sql = "SELECT * FROM users WHERE id = :id";
$stmt = $pdo->prepare($sql);
$stmt->execute(['id' => 1]);
$user = $stmt->fetch();
?>
Example 3: Password Hashing 
<?php
// Hashing a password securely
$hash = password_hash("secret", PASSWORD_DEFAULT);
// Verifying later
$isValid = password_verify("secret", $hash);
?>

أمثلة عملية

المثال ١: الاتصال بقاعدة البيانات عبر PDO 
<?php
$dsn = "mysql:host=localhost;dbname=testdb";
$pdo = new PDO($dsn, "user", "pass");
?>
المثال ٢: الجملة المُجهزة لحماية الاستعلام 
<?php

المثال ٣: تشفير كلمات المرور

// التحقق من صحتها لاحقاً

Real-World Use Case

User Authentication System: Processing a login form where user email is checked via a prepared statement (preventing injection), and their submitted password is validated against the stored secure hash.

حالة استخدام واقعية

نظام مصادقة المستخدمين: معالجة نموذج تسجيل الدخول حيث يتم فحص البريد الإلكتروني عبر استعلام مُجهز (لمنع اختراق قاعدة البيانات)، والتحقق من كلمة المرور المدخلة بمقارنتها مع النسخة المشفرة المخزنة.
